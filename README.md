# Mafia Multiplayer

A Node.js + Express + Socket.IO room-code game.

## Run
- Install Node.js 18+
- In this folder run `npm install`
- Run `npm start`
- Visit `http://localhost:3000`

For friends on different devices, deploy this project to a Node.js host that supports WebSockets, then share the deployed URL. Room codes are generated by the server.

Features: up to 12 players, 1–3 chosen imposters, exactly one doctor, random roles, private imposter chat, group target agreement, doctor healing, timed meetings, votes/ties, elimination announcements, and win checks.

This is a playable starter project, not yet a deployed public service. Rooms are in memory and clear on server restart. Add production security, moderation, reconnect handling, tests and persistent state before a public launch.
